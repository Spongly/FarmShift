# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of FarmShift and its users seriously.

If you discover a security vulnerability, please do NOT create a public issue on GitHub. Instead, responsibly disclose it via one of the following methods:

1. **GitHub Private Vulnerability Reporting:** Use the "Report a vulnerability" button under the **Security** tab of the [repository](https://github.com/Spongly/farmshift/security/advisories/new).
2. **Direct Contact:** Contact the project maintainer via [GitHub Profile](https://github.com/Spongly) or portfolio website at [https://pokhrelpratik.com.np/](https://pokhrelpratik.com.np/).

### What to Include:
- Description of the vulnerability.
- Steps to reproduce or proof of concept.
- Potential impact.

We will review reports promptly and publish fixes in a transparent, timely manner.

# Screenshots & Visual Previews

This directory contains visual captures of the running FarmShift application for documentation and repository preview.

## Included Views

- **Homepage & Public Service Portal:** Photo-led editorial interface, regional agroclimatic breakdown (Hills vs Terai), and step-by-step guidance.
- **My Farm Guided Planner:** Interactive coordinate picker, Nepalese presets (Kathmandu, Pokhara, Chitwan, Rupandehi, Mustang), soil texture, pH, and irrigation setup.
- **NASA Intelligence Dashboard:** Real-time satellite layer visualizations (SMAP Soil Moisture, MODIS LST, GPM IMERG Precipitation), live 30-day rainfall, and flood early warning advisories.
- **Climate Explorer:** Historical NASA POWER climatology normals, monsoon distribution, and thermal envelopes.
- **Crop Rotation Planner:** Multi-season crop rotation pathways, multi-criteria suitability scoring, and comparative trade-off matrix.

---

### Capturing Fresh Screenshots
To generate high-resolution application screenshots:
1. Start the development server: `npm run dev`
2. Open `http://localhost:5173` in your browser.
3. Save full-page or component captures to `docs/screenshots/` and update references in `README.md`.
